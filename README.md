# Taskly

Taskly — менеджер завдань, розроблений на Python із використанням принципів Clean Architecture, SOLID та патернів проєктування.

## Можливості

- Створення та редагування завдань.
- Керування статусами: заплановане, виконане, невиконане, скасоване.
- Відновлення архівних завдань.
- Налаштування пріоритету та розкладу.
- Збереження даних у JSON.

## Архітектура

- **Domain** — бізнес-модель і правила.
- **Application** — команди, запити та їхні обробники.
- **Infrastructure** — зберігання даних і робота з JSON.
- **Presentation** — взаємодія з користувачем.
